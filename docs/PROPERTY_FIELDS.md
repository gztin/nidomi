# Findhouse 房源欄位與刊登規則

- 文件狀態：MVP 房源表單與公開頁基準
- 更新日期：2026-07-11
- 參考基準：內政部現行住宅租賃定型化契約應記載及不得記載事項

> 本文件是產品規格，不是法律意見。法規可能修正，正式上線前應由台灣執業律師確認，並重新核對內政部最新公告。

## 1. 資料分級

### 1.1 公開資料

任何訪客可查看，用於判斷房源、費用及租屋條件。

### 1.2 確認預約後資料

只有已確認預約的找房者、房源提供者與管理員可查看，例如完整碰面資訊。完整門牌是否於此階段揭露，由房源提供者填寫碰面地點時決定。

### 1.3 私密管理資料

只有房源提供者與管理員可查看，例如完整門牌、管理聯絡資料及所有權文件。權利文件另受文件審核權限限制。

## 2. 基本資料

| 欄位 | 必填 | 公開 | 規則 |
|---|---|---|---|
| 房源標題 | 是 | 是 | 不得含電話、Email、銀行帳號或誤導文字 |
| 房源類型 | 是 | 是 | 整層、獨立套房、分租套房、雅房、其他 |
| 公開位置 | 是 | 是 | 縣市、行政區、路段或鄰近地標 |
| 完整門牌 | 是 | 否 | 私密管理資料，不得出現在公開 API |
| 租賃範圍 | 是 | 是 | 整戶、房間、共用區域、車位及附屬範圍 |
| 格局 | 是 | 是 | 房、廳、衛及其他空間 |
| 使用坪數 | 是 | 是 | 標示計算口徑，不能以不明坪數混用 |
| 所在／總樓層 | 是 | 是 | 需合理且一致 |
| 電梯 | 是 | 是 | 有、無 |
| 車位 | 是 | 是 | 無或類型、位置、費用 |
| 可入住日期 | 是 | 是 | 不得早於刊登日 |
| 最短租期 | 是 | 是 | 以月表示 |

## 3. 租金、押金與支付

| 欄位 | 必填 | 公開 | 規則 |
|---|---|---|---|
| 每月租金 | 是 | 是 | 正整數、新臺幣 |
| 押金 | 是 | 是 | 不得超過兩個月租金 |
| 租金支付週期 | 是 | 是 | 月付或其他明確週期 |
| 支付期限 | 是 | 是 | 說明每期應付日期 |
| 支付方式 | 是 | 否 | 簽約前提供，不公開帳號 |
| 管理費 | 是 | 是 | 金額、週期及負擔方；無則明示 0 |
| 停車費 | 條件式 | 是 | 有車位或另租車位時必填 |
| 其他費用 | 否 | 是 | 每項需有名稱、金額或計算方式、週期及負擔方 |

平台不得提供將依法應由出租人負擔的稅賦概括轉嫁給承租人的選項。

## 4. 水電與其他公用費用

### 4.1 電費按度計費

必填：

- 是否使用獨立電表。
- 計費依據為電費單當期每度平均電價。
- 用電度數及電費資訊提供方式。
- 屋內或屋外公共用電是否分攤及計算方式。

每度計價不得高於電費單當期每度平均電價。無法提供計算依據時不得刊登任意固定高額單價。

### 4.2 電費非按度計費

必填：

- 每期電費總額的取得方式。
- 承租人分攤比例或金額計算方式。
- 電費資訊提供方式。

房源提供者收取的合計不得超過該期電費總額；未納入電費單的屋外公共設施電費不得另行加收。

### 4.3 其他費用

- 水費：依帳單、按人、固定金額或其他明確計算方式。
- 瓦斯：天然氣帳單、桶裝瓦斯分攤或無。
- 網路及有線電視：是否包含、金額及負擔方。
- 每項費用必須公開計算方式，不得只填「另計」。

## 5. 家具、設備與點交準備

可選設備至少包含：

- 冷氣、冰箱、洗衣機、熱水器
- 床、床墊、衣櫃、桌椅
- 廚房、爐具、抽油煙機
- 網路、電視
- 門禁、保全、對講機
- 陽台、曬衣設備
- 住宅用火災警報器、滅火器及其他消防設備
- 垃圾處理方式

每項設備保存數量、現況、是否專用／共用及備註。資料結構需可在未來沿用至點交附件；設備有已知故障時必須揭露。

## 6. 使用條件

允許設定：

- 可否養寵物及合理限制
- 可否開伙
- 可否吸菸
- 可入住人數
- 是否允許轉租（仍須符合法令及契約）
- 公共區域或大樓管理規約
- 其他具體、合理且合法的使用限制

不得提供或接受以下內容：

- 禁止承租人申請租金補貼
- 禁止承租人遷入戶籍
- 禁止承租人申報租賃費用支出
- 將依法應由出租人負擔的稅賦增加概括轉嫁承租人
- 免除或限制出租人故意不告知瑕疵的責任
- 要求承租人繳回契約書
- 約定通知只能使用電話
- 宣稱「廣告僅供參考」以全面排除刊登責任
- 其他違反強制或禁止規定的條件

結構化欄位不得出現上述選項；自由文字在儲存時進行禁止內容檢查，無法判定時送管理員人工檢查。

## 7. 修繕、管理與重大現況

必填或明確回答：

- 一般修繕責任與聯絡方式
- 緊急事件聯絡方式
- 是否委託管理人及其聯絡方式
- 已知漏水、壁癌、設備故障或其他瑕疵
- 是否有增建、分租或共用空間
- 熱水器類型與安裝位置
- 消防及逃生設備
- 基地台、水箱、中繼幫浦機械室或其他可能影響居住使用的設施
- 其他房源提供者已知且足以影響承租決定的事項

不得只用「無重大瑕疵」取代逐項回答。公開頁顯示與承租判斷有關的資訊；私人管理聯絡資料不公開。

## 8. 圖片與附件

- 公開照片不得出現身分證、權利文件、銀行帳號、私人信件或第三人可辨識個資。
- 圖片需對應實際租賃範圍，不得以公共設施或他戶照片造成誤認。
- 照片修改不得改變格局、設備或瑕疵等實質資訊。
- 房源設備清單、費用表與公開附件需保存版本，未來可作為契約相關附件。

## 9. 重要條件變更

以下欄位變更需建立房源版本：

- 租金、押金及所有費用
- 電費與公用費計算方式
- 租賃範圍、格局及可入住日期
- 重要設備、已知瑕疵與重大現況
- 使用條件與限制

若房源已有待確認或已確認預約，系統需通知受影響會員。已確認預約的房客應能查看預約當時版本與最新版本的差異；房源提供者不能用修改公開頁方式靜默取代原始條件。

## 10. 刊登驗收條件

1. 必填欄位完整且格式合理。
2. 押金不超過兩個月租金。
3. 所有費用都有金額或計算方式、週期及負擔方。
4. 電費欄位符合所選計費方式與現行上限規則。
5. 禁止內容無法透過結構化欄位或自由文字刊登。
6. 公開 API 不回傳完整門牌、支付帳號、管理聯絡資料或驗證文件。
7. 設備與已知現況有明確紀錄。
8. 重要條件變更保存版本並通知受影響會員。
9. 管理員可查看被阻擋或待人工檢查的原因與歷程。
