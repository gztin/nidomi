# Findhouse MVP 使用者流程

- 文件狀態：低保真體驗基準
- 更新日期：2026-07-11

## 1. 找房者流程

```mermaid
flowchart TD
    A["瀏覽單一房源"] --> B["查看照片、費用、設備、限制與驗證狀態"]
    B --> C["選擇申請約看"]
    C --> D{"是否登入？"}
    D -->|否| E["登入或註冊"]
    E --> F{"Email 已驗證？"}
    D -->|是| F
    F -->|否| G["寄送驗證信／等待驗證"]
    G --> H["驗證成功並返回原流程"]
    F -->|是| R{"符合房東預約門檻？"}
    R -->|是| I["選擇可約時段"]
    R -->|否| S["前往身分驗證；時段不保留"]
    S --> R
    H --> R
    I --> J["填寫電話、人數與留言"]
    J --> K["確認條件與送出"]
    K --> L["取得預約編號／待確認"]
    L --> M{"房源提供者處理"}
    M -->|確認| N["查看碰面資訊並收到通知"]
    M -->|取消或逾期| O["查看原因／重新選擇時段"]
    N --> P["現場核對預約編號"]
    P --> Q["約看完成"]
```

### 1.1 中斷與返回

- 註冊、登入或 Email 驗證完成後，返回原房源與約看步驟。
- 時段在送出前被他人占用時，保留已填電話、人數與留言，返回時段選擇。
- 工作階段逾期時，重新登入後恢復尚未送出的表單草稿；不自動建立預約。

## 2. 房源提供者流程

```mermaid
flowchart TD
    A["我的房源"] --> B["維護房源、照片、費用、設備與條件"]
    B --> C["設定未來 30 天可約時段"]
    C --> D["收到待確認申請"]
    D --> E["查看租客資料、時段與留言"]
    E --> F{"處理申請"}
    F -->|確認| G["填寫聯絡人、聯絡方式、碰面地點"]
    G --> H["確認並通知找房者"]
    F -->|取消| I["填寫原因並通知"]
    H --> J["必要時修改碰面資訊並通知"]
    J --> K["標記完成"]
    D -->|超過期限| L["系統自動取消"]
```

### 2.1 時段管理

- 每場固定 60 分鐘，只能建立未來 30 天時段。
- 已被申請的時段不可直接刪除或靜默關閉。
- 取消後距開始至少 12 小時才重新開放，否則關閉。

## 3. 所有權文件流程

```mermaid
flowchart TD
    A["房源提供者查看驗證狀態"] --> B["閱讀敏感資料告知"]
    B --> C["上傳所有權文件"]
    C --> D["待審核"]
    D --> E{"管理員決定"}
    E -->|通過| F["更新內部文件審核狀態"]
    E -->|補件| G["查看原因並建立新版本"]
    G --> D
    F -->|資料變更／失效／撤銷| H["更新內部審核狀態"]
```

## 3A. 會員身分驗證流程

```mermaid
flowchart TD
    A["一般會員查看驗證狀態"] --> B["閱讀敏感資料告知"]
    B --> C["填寫身分證字號並上傳正反面"]
    C --> D["待管理員審核"]
    D --> E{"審核決定"}
    E -->|通過且 Email 已驗證| F["取得綠色認證會員徽章"]
    E -->|需要補件| G["查看私人原因並重新提交"]
    E -->|拒絕| H["顯示拒絕狀態與申訴入口"]
    G --> D
    F -->|資料失效或撤銷| I["移除綠色標章"]
```

身分驗證不是約看門檻；租客完成 Email 驗證後即可申請約看。

## 4. 管理員流程

```mermaid
flowchart TD
    A["管理首頁"] --> B["查看會員、房源、預約、文件與異常"]
    B --> C["文件待審核列表"]
    C --> D["開啟受控預覽並留下存取紀錄"]
    D --> E{"審核決定"}
    E -->|通過| F["核發標章並通知"]
    E -->|補件| G["選擇原因並通知"]
    E -->|撤銷／失效| H["移除標章並記錄理由"]
    B --> I["檢舉與申訴"]
    I --> J["警告／補件／下架／限制／停權"]
    J --> K["保存管理稽核"]
```

## 5. 角色切換與導覽

- 所有登入會員顯示「我的約看」。
- 擁有房源的會員另顯示「我的房源」、「收到的預約」與「可約時段」。
- 管理員另進入獨立管理區，不在一般會員畫面混入全站資料。
- 同一會員不得預約自己提供的房源。
